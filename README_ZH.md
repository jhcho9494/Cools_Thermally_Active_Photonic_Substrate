# Cools 热主动光子基板平台

[English](README.md) | [한국어](README_KR.md) | [专利架构](PATENT_PORTFOLIO.md) | [公开说明](PUBLIC_NOTICE.md)

## 埋置绝缘层不再只是光学包层。
## 它同时成为连接光子器件层与高导热承载体的可设计热通路。

**Cools 热主动光子基板平台**将传统光子绝缘体上硅（Photonics-SOI）中的固定功能二氧化硅埋置绝缘层（Buried Insulator，BOX）替换为**氧化铝系 BOX**，并在其下方配置反应结合碳化硅（Reaction-Bonded Silicon Carbide，RBSC）、烧结 SiC、AlN 或金刚石复合材料等**高导热承载体**。

该平台旨在把光学约束、散热、机械支撑、垂直电连接、中介层功能和冷板接口集成到同一基板堆叠中。

---

## 1. 传统光子基板的核心瓶颈

传统 Photonics-SOI 由硅光子器件层、SiO₂ BOX 和硅承载晶圆组成。SiO₂ 具有良好的光学隔离能力，但其低热导率会在调制器、光探测器和热光相移器（Thermo-Optic Phase Shifter，TOPS）下方形成热瓶颈。

由此产生一系列固定折衷：

- 光学隔离与热抽取之间的折衷；
- TOPS 效率与复位速度之间的折衷；
- 调制器外部热扰动隔离与自身平均发热排出之间的折衷；
- 高密度光集成与通道间热串扰之间的折衷；
- 光子集成与额外中介层、散热层之间的折衷。

Cools 同时重新定义 BOX 与承载体的功能。

---

## 2. 核心基板架构

```text
光子器件层
    ↓
氧化铝系埋置绝缘层
（光学包层 + 热传导路径）
    ↓
界面结合层
    ↓
高导热承载体
（基板 + 中介层 + 热扩散体 + 冷却接口）
```

### 氧化铝系 BOX

BOX 可包括：

- 单晶蓝宝石薄膜；
- 晶态氧化铝；
- 非晶氧化铝；
- 阳极氧化铝（Anodic Aluminum Oxide，AAO）；
- 致密氧化铝与多孔 AAO 的复合堆叠。

同一绝缘层同时承担：

1. 下部光学包层与光泄漏抑制；
2. 从光子器件层到高导热承载体的热传导路径。

### 高导热承载体

承载体可包括 RBSC、烧结 SiC、CVD 多晶 SiC、AlN、金刚石复合材料、AlSiC、Cu-Mo、Cu-W 或石墨复合材料。一个承载体可集成传统上由多个独立部件承担的功能：

- 机械基板；
- 热扩散体；
- 电/光中介层；
- 封装支撑体；
- 冷板连接面。

## 3. 平台创新轴

### A. 可重复回收的单晶蓝宝石 BOX

通过重复薄膜分离循环，从单晶蓝宝石供体中仅回收微米级薄膜作为 BOX，而不是消耗整片厚蓝宝石晶圆。外部高导热承载体负责机械支撑和热扩散。

### B. 区域差异化孔隙率 AAO BOX

同一光子基板内，可针对光路、调制器、滤波器及 TOPS 区域设置不同 AAO 孔隙率，从而分别调节有效折射率、弹性模量和热导通能力。

```text
光路/滤波区域 → 更强光学约束
调制器区域    → 光学与热响应平衡
TOPS 区域     → 局部热约束与快速放热优化
```

这消除了整个芯片只能采用单一 BOX 规格的限制。

### C. 可变热导通中间层

可在调制器或 TOPS 下方的 BOX 与承载体之间设置由外部信号控制的可变热导通层。

- 相位移动或保持期间：低热导状态，将热量局限在局部区域；
- 复位、冷却或空闲期间：高热导状态，将热量释放到承载体；
- 调制器区域：根据 enable、burst、idle、平均功率或温度信号动态改变热通路。

其实现机制可包括相变材料、可变微接触、流体微通道以及压电接触压力控制。

### D. 光区/电区分离与热膨胀匹配 THV

同一基板可平面划分为光学区域和电学区域。

- 光学区域保留 BOX，以维持光模式约束；
- 电学区域局部将 BOX 替换为电绝缘支撑层；
- 形成贯穿高导热承载体的贯穿承载体通孔（Through-Handler Via，THV）。

THV 可由与承载体热膨胀系数匹配的陶瓷或复合机械骨架，以及位于其内部或表面的导电芯/导电衬层组成。热机械承载与电导通由不同结构单元承担，从而在无需独立硅中介层的情况下实现基板级光电共集成。

### E. 中红外 Si₃N₄ 光子平台

通过将 Si₃N₄ 波导芯与氧化铝系上下包层结合，可规避传统 SiO₂ BOX 与包层在中红外波段的吸收限制。

- 1.55 μm 通信区域；
- 2–5 μm 中红外区域；
- 区域差异化 BOX 厚度与包层材料；
- 气体传感、光谱分析与自由空间光学集成。

### F. InP-on-SiC 汽车激光雷达

将 InP 系 III-V 光功能薄膜转移到 SiC 散热支撑平台上，可集成 1.5 μm 级光源、探测器、光波导、调频连续波（Frequency-Modulated Continuous Wave，FMCW）接收器和光学相控阵（Optical Phased Array，OPA）。

目标包括：

- 抑制光源结温上升；
- 稳定中心波长和线宽；
- 提高 FMCW 与 OPA 的相位稳定性；
- 改善汽车振动和热循环可靠性；
- 通过 InP 供体重复利用提高材料效率。

## 4. 从被动基板到主动系统基础设施

| 传统光子基板 | Cools 热主动光子基板 |
|---|---|
| BOX 主要用于光学隔离 | BOX 同时提供光学隔离和可设计热通路 |
| 热导通固定 | 可按区域和时间改变热导通 |
| 整片基板只有一种 BOX 规格 | 各区域可具有不同光学、弹性和热学特性 |
| PIC、电子电路和中介层分离 | 基板级光电共集成 |
| 硅承载体需要额外散热堆叠 | 高导热承载体集成热扩散和冷却接口 |
| 以近红外为主 | 扩展至中红外和汽车 LiDAR |

## 5. 应用领域

- 共封装光学（Co-Packaged Optics，CPO）；
- 硅光子和 Si₃N₄ 光子集成电路；
- 高密度波分复用；
- TOPS 阵列；
- 光学相控阵；
- 1.55 μm 相干汽车激光雷达；
- 中红外气体与化学传感；
- 集成光谱仪；
- 光计算与光互连；
- 量子与非线性光子系统。
